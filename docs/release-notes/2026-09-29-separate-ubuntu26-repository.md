# Ubuntu 26 전용 저장소 분리

## 변경 요약

26.04 대응 및 xrandr 배치 폐기 작업을 `devchan64/ubuntu26-legion5-setup` 독립 저장소로 배포합니다.

## 주요 변경사항

- 기존 이력과 26.04 대응 커밋을 계승합니다. 기존 저장소의 되돌림 커밋은 가져오지 않습니다.
- README의 저장소 이름과 복제 명령을 갱신했습니다.
- 상태·재부팅 경계·다운로드 경로를 `~/.local/state/ubuntu26-legion5-setup/`으로 분리했습니다.
- 기존 24.04 호환 경로는 유지합니다.

## 영향 범위

이전 릴리즈 노트의 `ubuntu24` 상태 경로 유지 설명은 이 저장소에서는 적용하지 않습니다.
기존 상태 파일은 복사하거나 삭제하지 않습니다. 새 저장소의 설치 상태는 처음부터 기록됩니다.
OS 자체 업그레이드와 현재 PC의 설정 변경은 수행하지 않습니다.

## 기대 효과

기존 24.04 저장소에 26.04 변경을 다시 푸시하지 않고 독립적으로 배포·관리할 수 있습니다.

## 검증

- Bash 구문, OS 계약 및 sys 분기 테스트, 공백 오류 검사.
- 26.04 실기기 전체 설치는 미검증입니다.
