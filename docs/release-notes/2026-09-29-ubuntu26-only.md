# Ubuntu 26.04 전용 코드 정리

## 변경 요약

새 저장소에서 Ubuntu 24.04 호환 코드를 제거했습니다.

## 주요 변경사항

- OS 계약은 Ubuntu 26.04/resolute만 허용합니다.
- Xorg 설치 스크립트와 세션 환경 추출 코드를 제거했습니다.
- sys 명령은 Wayland 설정만 실행합니다.
- CUDA 13.0.2 로컬 저장소 설치, 다운로드 및 오류 시 저장소 삭제 경로를 제거했습니다.
- 문서와 주석, 회귀 테스트를 전용 정책에 맞췄습니다.

## 영향 범위

24.04 실행은 거부합니다. 이전 릴리즈의 호환성 유지 설명을 대체합니다.
이미 기록된 26.04 resume 파일 경로와 stepKey는 유지합니다.
기존 Xorg 강제 설정을 해제하는 마이그레이션 처리는 유지합니다.

## 기대 효과

26.04 설치 경로만 관리하며 구형 배포판 설정의 혼입을 방지합니다.

## 검증

Bash 구문 및 OS 계약 테스트, 24.04 거부와 Wayland 경로 선택 검증을 수행합니다.
26.04 실기기 설치는 미검증입니다.
