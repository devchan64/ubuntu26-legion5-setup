# SMB/NAS 파일 탐색기 및 일괄 이름 변경 추가

## 변경 요약

로컬 폴더와 SMB/NAS 공유를 탐색하고 파일 이름을 정렬하거나 일괄 변경할 수 있는 GTK 도구를 추가했습니다.

## 주요 변경사항

- `scripts/net/file-explorer.py`에 GVFS URI 기반 파일 탐색기를 추가했습니다.
- `smb://서버/공유이름` 형식의 SMB/NAS 경로를 위치 입력란에서 열 수 있습니다.
- 도구 모음의 네트워크 탐색과 SMB 탐색 버튼으로 발견된 NAS 서버와 공유 폴더를 목록에서 탐색할 수 있습니다.
- SMB/NAS 인증 요청 시 사용자명·암호·도메인을 입력하는 인증 창을 표시하고, 암호는 GVFS 세션에만 전달합니다.
- SMB 공유가 마운트 가능한 위치로 반환돼도 기본 파일 관리자를 열지 않고 앱 내부 인증·마운트·탐색 흐름으로 처리합니다.
- 파일 이름 자연 정렬의 오름차순·내림차순과 폴더 우선 표시를 제공합니다.
- 파일 이름 정렬 비교에서 `-`, `.`, `_`를 무시합니다.
- 파일 목록에 사람이 읽기 쉬운 용량 열을 추가하고, 폴더 용량은 계산하지 않습니다.
- 기본 탐색은 단일 선택이며, 선택 모드에서만 다중 선택, 전체 선택, 선택 해제 및 일괄 작업을 제공합니다. 현재 폴더 이름 검색을 지원합니다.
- 선택 모드 UI에 `Shift+클릭` 범위 선택, `Ctrl+클릭` 개별 추가·해제 안내와 단일 선택 해제 버튼을 추가했습니다.
- 선택 모드에서 GTK 기본 처리와 무관하게 `Shift+클릭` 범위 선택과 `Ctrl+클릭` 개별 토글을 적용합니다.
- 일괄 이름 변경에서 기존 이름이나 선택 항목과 충돌한 항목은 변경하지 않고 건너뛴 사유를 보고합니다.
- 일괄 이름 변경에서 파일 확장자를 포함해 이름을 대문자 또는 소문자로 변환할 수 있습니다.
- 삭제 확인 뒤 로컬 항목은 휴지통으로 이동하고 SMB/NAS 항목은 영구 삭제하며, 실패 항목은 사유를 보고합니다.
- 상단 도구 모음을 3행으로 재배치해 이동·경로, 선택 모드·일괄 작업, 정렬·선택 제어·검색을 각각 분리했습니다.
- 선택한 항목에 접두사, 접미사, 찾아바꾸기, 연속 번호를 적용하기 전에 결과를 미리 보여 줍니다.
- 네트워크 도구 설치에 GTK Python 바인딩과 GVFS 백엔드를 포함했습니다.

## 적용 설정

`./scripts/install-all.sh net` 실행 후 `python3 ./scripts/net/file-explorer.py`로 실행합니다. 이전에 `net` 단계를 완료한 환경은 `bash ./scripts/install-all.sh net --reset`으로 새 의존성을 설치합니다.

## 기대 효과

GNOME 파일 관리자와 별도로, 로컬과 NAS 파일에 동일한 이름 정리 규칙을 적용할 수 있습니다.
